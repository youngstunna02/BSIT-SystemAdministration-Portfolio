# Week 02 – Enterprise Infrastructure Planning

## Project Overview

ABC Startup Solutions is a newly established software development company with 20 employees. This project focuses on planning an initial IT infrastructure for the company before the purchase and deployment of its technology resources. The plan covers the company's hardware, software, network infrastructure, system administration roles, and infrastructure recommendations.

The project aims to create a reliable, secure, scalable, and organized IT environment that can support the company's daily operations and future growth.

---

## Learning Objectives

By completing this project, I aim to:

- Understand the basic process of planning an enterprise IT infrastructure.
- Identify appropriate hardware and software requirements for an organization.
- Design a logical enterprise network topology.
- Understand the functions of routers, switches, firewalls, servers, and wireless access points.
- Identify the responsibilities of different system administration roles.
- Develop proper IT infrastructure documentation.
- Understand the importance of security, backup, reliability, and future scalability.
- Improve my skills in network and system administration planning.

## System Administration Roles

### Helpdesk Technician

A Helpdesk Technician provides first-level technical support, troubleshoots hardware and software problems, assists users, documents incidents, and escalates complex problems to other IT professionals.

### How the Four Professionals Work Together

The four professionals work together to maintain a reliable, secure, and efficient IT environment within an organization. The **Helpdesk Technician** serves as the first point of contact for employees by handling common hardware, software, and technical issues. When problems involve network connectivity or network devices, the **Network Administrator** manages and troubleshoots the organization's network infrastructure. The **Linux System Administrator** maintains Linux-based servers, manages system services, users, storage, and security, while the **Cloud Administrator** manages cloud-based resources, services, security, storage, and virtual infrastructure. By communicating and coordinating with one another, these professionals can resolve technical problems efficiently, maintain system availability, protect company resources, and ensure that employees have reliable access to the IT services they need.

## Infrastructure Recommendations

### Internet Service Provider

A reliable business-grade ISP should be selected to provide stable internet connectivity for the company's 20 employees. The selected plan should provide sufficient bandwidth for software development, cloud services, video conferencing, file transfers, and normal business operations.

### Server Specifications

The company should use a dedicated server with sufficient processing power, memory, and storage to support centralized services and future growth.

**Recommended minimum specifications:**

| Component | Recommendation |
|---|---|
| Processor | Intel Xeon or AMD EPYC |
| Memory | 32 GB RAM |
| Storage | 2 × 1 TB SSD |
| Network | Gigabit Ethernet |
| Operating System | Ubuntu Server 24.04 LTS |
| Backup | NAS + External Backup Drives |

### Backup Strategy

The company should implement a regular backup strategy using the server, NAS storage, and external backup drives. Important files should be backed up regularly, with at least one backup copy stored separately from the main network.

### Security Recommendations

- Use a firewall to protect the internal network.
- Enable Microsoft Defender on Windows computers.
- Keep operating systems and applications updated.
- Use strong passwords and account policies.
- Apply user access permissions based on job responsibilities.
- Restrict administrator privileges.
- Regularly monitor network and system activity.
- Provide cybersecurity awareness training for employees.

### Password Policy

Employees should use strong and unique passwords. Passwords should not be shared between users and should be changed whenever an account is suspected of being compromised. Multi-factor authentication should be enabled for supported services.

### Future Expansion

The infrastructure should allow the company to add additional employees and network devices without completely redesigning the network. Additional switch ports, wireless access points, storage capacity, and server resources can be added as the company grows.

## Challenges Encountered

One of the most challenging parts of the project was designing the enterprise network topology. I needed to make sure that all required networking devices and departments were included while maintaining logical connections between them. Another challenge was selecting realistic quantities of hardware and software for a company with 20 employees. I also needed to consider security, backup, reliability, and future expansion when making infrastructure recommendations. These challenges helped me understand that system administration requires careful planning and decision-making rather than simply selecting technology based on specifications.

## Reflection

This project helped me understand that system administration involves more than simply installing computers, software, and network devices. I learned how important it is to plan an organization's IT infrastructure based on its actual needs. By creating the company profile and hardware, software, and network inventories, I learned how to identify the resources required to support employees and daily business operations. I also gained a better understanding of how different networking devices, such as routers, switches, firewalls, and wireless access points, work together to provide a reliable network.

The most challenging task for me was designing the enterprise network diagram. I needed to make sure that all required components were included and that the connections between the Internet, ISP modem, router, firewall, switch, server, printer, wireless access point, and departments were logically arranged. This task helped me realize that even a small mistake in network planning can affect how an entire infrastructure is designed.

Planning is important before deployment because it allows a System Administrator to understand the organization's requirements before purchasing and configuring equipment. Proper planning can help prevent unnecessary expenses, reduce configuration problems, improve network security, and make future maintenance and expansion easier.

This project will help me become a better System Administrator because it gave me practical experience in planning an IT infrastructure from the beginning. It improved my skills in analyzing requirements, selecting appropriate hardware and software, designing a network topology, documenting technical information, and understanding different system administration responsibilities. Overall, this project gave me a better understanding of how System Administrators contribute to the success of an organization.
